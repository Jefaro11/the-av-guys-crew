# The AV Guys Crew PWA

1. Deploy to GitHub Pages.
2. Open the HTTPS Pages URL on iPhone Safari.
3. Add the site to the Home Screen.
4. Open the Home Screen app.
5. Sign in with the crew account.
6. Tap Enable notifications.
7. Register a crew assignment from the AV Guys Mac app and confirm/send the event notification.

Web Push requires an HTTPS origin and is supported for iPhone/iPad Home Screen web apps on iOS/iPadOS 16.4 and later.
