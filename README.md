# The AV Guys Crew

The AV Guys Crew is the iPhone Home Screen web app for crew schedules, notifications and event equipment control.

Features: event assignments, Accept / Decline responses, Web Push notifications, equipment QR/manual scanning, and equipment issue logging.

Hosted app: https://jefaro11.github.io/the-av-guys-crew/

Use Safari on iPhone → Share → Add to Home Screen. Open the Home Screen app and enable notifications.
